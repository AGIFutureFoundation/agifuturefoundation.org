The fabric data is live as JSON on GitHub Pages, the 3D models and map service are still to host, and the public endpoint is planned on an Oracle free-tier server

SAN FRANCISCO — Nov. 6, 2026 — The AGI Future Foundation is giving a straight account of the state of its metaverse fabrics: six anchored fabrics have their data live as JSON on GitHub Pages, the 3D model files and the map service are still to be hosted, and no world is live on RP1. This release states the position as it stands, without rounding it up.

The six anchored fabrics are the ones with live JSON data served from GitHub Pages. That data describes the worlds, their contents, and their layout, and it is publicly retrievable. What is not yet public is the rest of the stack. The 3D model files behind the fabrics — 168 unique GLB files, referenced 271 times across the fabrics — are still to be hosted. The map service, built on map.wasm, is staged locally and still to be hosted. Until those pieces have a public home, the fabrics can be read as data but cannot be walked through as worlds.

No world is live on RP1. That is the position today, stated plainly. Work toward a public map-service endpoint is planned on an Oracle Cloud Always Free server, which the Foundation has chosen as the host for the always-on endpoint. No account has been created yet, no server is running, no money has been spent, and no public endpoint exists. The Oracle email-verification step is still in progress, and the tenancy name needed to sign in has not yet arrived.

The Foundation is not presenting the fabrics as a finished product, and this release does not ask readers to treat them as one. The fabrics are a build in progress, and the honest description of that build is that the data layer is public, the model and service layers are not, and the RP1 worlds are not live. The map service itself runs locally today, with its database installed and its fabric endpoints answering, but a service running on one machine is not a public endpoint, and the Foundation will not describe it as one. When the models are hosted and the public endpoint is running, that will be a new fact to report, and it will be reported then.
