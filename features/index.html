Features — the Family, Up Close

Eleven features on the work and the plans of the AGI Future Foundation family — the listening machines, the biotech swarms, the classrooms, the trade halls, the robot governors, the worlds on real maps, the legal armor, the watchers, the agent economy, the idea that holds them all together, and the agentic venture studio built to make a better world: agents operate, people govern.

Start with The WAVESee all ten

A reading note, before the music starts:
These are magazine-style features — punchy ledes, scene-setting, cultural framing — about real work and stated plans. They are not news reports. No feature contains an interview, a quote from a named person, or a statistic presented as established fact. Where a project describes itself in big numbers, the feature says so in those words. Where something is planned rather than built, the feature says that too. The family is a filed California nonprofit with a large intended network; the features keep the filed facts and the intended plans visibly apart.

The eleven features

Feature 01

The WAVE — Listening to the Earth

BioDao's bet: if we can hear the living world clearly enough, we can defend it. Whales, wild voices, and a real-time translation engine.

Feature 02

The Biotech Swarm

Agent swarms for genomics, proteomics, and drug discovery — ambitious, early, and honest about it.

Feature 03

The Flow Zone

Cognition.X turns learning into modular frameworks. Education first, AGI second — in that order, on purpose.

Feature 04

The Trade Craft Academy

SmartCiti.X wants to train humans and robots side by side — union trades, AR/VR, and a Holodeck that is still being built.

Feature 05

The Physical-AI Governors

Robotics DAO: who governs the machines that move in the physical world, and what the gates look like.

Feature 06

Worlds on Real Maps

WorldForge builds training worlds on real Earth maps — satellite, elevation, streets, robot twins. The road to RP1, told straight.

Feature 07

The Shield and the Windfall

The governance story: legal armor for safety-first decisions, and a promise to share the upside before the money arrives.

Feature 08

The Watchers

Sentinel Stream and PlaudGuard-AI: agents watching agents, threats caught in real time, meetings turned into compliance.

Feature 09

The Agent Economy

Metropolis and Insidr: agent identity, micropayments, and steward governance — an economy where the workers are software and the bosses are human.

Feature 10

Agents Operate, People Govern

The through-line: thirty-three series, one church partner, one event assistant, one swarm — and the rule that ties them together.

Feature 11 · Spotlight

The Agentic Venture Studio — How the Foundation Is Working to Make a Better World

The studio model: agents run the day-to-day inside human-set limits, humans decide, and the mission gate holds — the spotlight piece of this series.

How to read this series

Each feature stands alone, and each ends with two boxes: What this is / What it isn't, and Where to see it — links to the real GitHub repository and to the Foundation's own series, project, or governance page for the same work. Read them in order for the arc, or jump to the one that catches you.

Every feature carries the same status line: the W3 series are intended and planned, not formed, funded, or offered, named in the April 2026 internal W3 series list. Nothing in this series is an offering, and nothing here is legal, tax, or financial advice.
